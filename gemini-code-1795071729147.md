# Project 01 — Streamlit Application

Interactive Streamlit web application built from the **Project 01** Colab workflow[cite: 6].

## Features
- **Data Exploration:** Inspect `train`, `validation`, and `test` splits, column types, missingness, target counts, `G2` score distributions, and mean `G2` by `studytime`[cite: 6].
- **Supervised Classification:** Predicts `needs_support` using a `OneHotEncoder` + `DecisionTreeClassifier(max_depth=4)` pipeline and compares against a `DummyClassifier(strategy="most_frequent")` baseline[cite: 6].
- **KMeans Clustering:** Groups student features (`k=3`) with `StandardScaler` + `KMeans` and assigns custom profiles[cite: 6].
- **CNN Digit Classifier:** Evaluates `28×28×1` grayscale digit images from `images.npz` and supports custom image uploads[cite: 6].
- **Supporting Assets:** Browse `feedback.csv`, `image_manifest.csv`, `prompt_test_cases.json`, `topic_keywords.json`, and `sample_images/`[cite: 6].
